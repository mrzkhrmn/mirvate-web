React Native uygulamalarında performans, tek bir ayardan değil ölçüm + iterasyon döngüsünden gelir.

## Hızlı kazanımlar

1. Hermes motorunu etkin tutun.
2. FlatList / FlashList ile pencereleme kullanın.
3. Reanimated ile UI thread animasyonları tercih edin.
4. Gereksiz re-render'ları React DevTools ile izleyin.
